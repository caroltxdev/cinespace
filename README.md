# 🎬 Cinespace

> Sua jornada cinematográfica em um só lugar

Cinespace é uma aplicação web para gerenciamento de filmes e séries que você deseja assistir, está assistindo ou já assistiu. Organize sua lista, avalie títulos e acompanhe seu progresso cinematográfico!

## ✨ Funcionalidades

- 📝 **Adicionar filmes e séries** com informações detalhadas
- 🎯 **Organizar por status**: Quero Assistir, Assistindo, Já Assisti
- ⭐ **Sistema de avaliação** de 1 a 5 estrelas
- 🎭 **Categorias por gênero** (Drama, Comédia, Ação, etc)
- 📺 **Plataformas de streaming** (Netflix, Prime, Disney+, etc)
- 💾 **Persistência local** - seus dados não se perdem
- 📊 **Estatísticas** em tempo real
- 🔍 **Filtros inteligentes** por status
- 📱 **Responsivo** - funciona em qualquer dispositivo

## 🚀 Tecnologias Utilizadas

- **React 18** - Biblioteca JavaScript para interfaces
- **Vite** - Build tool moderna e rápida
- **CSS3** - Estilização com variáveis CSS
- **LocalStorage** - Persistência de dados no navegador

## 🎨 Design

- Paleta de cores inspirada em Netflix
- Tipografia: Bebas Neue + Inter
- Tema dark cinematográfico
- Animações suaves e micro-interações
- Cards com efeito hover elegante

## 📦 Como Rodar Localmente

### Pré-requisitos

- Node.js 16+ instalado
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/watchbloom.git

# Entre na pasta
cd cinespace

# Instale as dependências
npm install

# Rode em modo desenvolvimento
npm run dev

# Abra no navegador
# Geralmente em http://localhost:5173
```

### Build para Produção

```bash
npm run build
npm run preview
```

## 📚 Aprendizados

Este projeto foi desenvolvido para demonstrar conhecimento em:

1. **Gerenciamento de Estado** - Como organizar e atualizar dados de forma eficiente
2. **Persistência** - Salvar dados localmente com localStorage
3. **Componentização** - Dividir a interface em componentes reutilizáveis
4. **Ciclo de Vida** - Usar useEffect para carregar e salvar dados
5. **Filtragem de Dados** - Implementar filtros dinâmicos
6. **Design Responsivo** - Interface que funciona em todos os dispositivos
